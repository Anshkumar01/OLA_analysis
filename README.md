This project focuses on analyzing ride booking data from OLA to uncover insights about customer behavior, ride trends, cancellations, and revenue patterns. The goal is to use data analytics to improve operational efficiency and customer experience.

🔧 Tech Stack Used:

PostgreSQL – for storing and querying ride data
Python – for data cleaning and preprocessing
Power BI – for building interactive dashboards
Gamma AI – for creating presentations

📊 Key Analysis Performed:

Ride booking trends (daily, weekly, peak hours)
Customer vs Driver cancellation analysis
Revenue and payment method insights
Vehicle type usage distribution
Customer segmentation (new, returning, loyal users)
TAT (Turnaround Time) analysis

📈 Project Objectives:

Identify patterns in ride demand
Reduce ride cancellations
Improve customer satisfaction
Optimize pricing and driver allocation

📌 Insights Generated:

Peak booking hours and high-demand locations
Major reasons behind ride cancellations
Most preferred payment methods
High-value customer segments
